## 2. 方法与数据

<a id="s2-1" name="s2-1"></a>

### 2.1 数据

- 天天基金 `pingzhongdata`：用**单位净值 + 累计净值差**还原分红，按除息日再投资；日频。1.2 的指标为 2008-01-02—2026-10-19；其中 2008—2016 为指数/同类代理，2017+ 逐步切换为实际净值。
- 候选 37 只 + 货币代理 000198；实盘货币用 000009，最终三组各持有 25 只、16 类；1.1 备选表共 46 个代码，不等于实际持仓数。
- 基金净值已扣管理费、托管费、销售服务费；回测额外扣 10bp 单边交易成本；不再另减年费。

<a id="s2-2" name="s2-2"></a>

### 2.2 回测规则

- **月度再平衡**：每月首个可用净值日按目标权重再平衡；月内买入持有，权重自然漂移。
- **成本**：每次换手收 10bp；按月度再平衡，不做日度再平衡。
- **无杠杆、无衍生品、不做空**；只用场外公募基金。
- **组合权重**：1000 轮定向扰动 + 类型上限约束；基金层精确到 0.1%，按 1.1 拆分执行。
- **优化**：在 2008—2026 上做 1000+ 轮定向搜索；档位只按 CAGR 判定，R2/R3 用最小必要权重补足 6/8；单只基金/单类上限 ≤50%，每只基金 ≥0.1%。

### 2.4 验证

- **权重校验**：R1-R3 的类型权重、基金权重均合计 100%；三组均 16 类 / 25 只，R1/R3 每只 ≥0.1%，R2 允许部分类型为 0。
- **再平衡实现**：每个再平衡日先归位到目标权重，再按换手扣 10bp 成本；不是买入持有。
- **独立复算**：另写价值法脚本，从原始 CSV 重新加载、按月再平衡、逐日记账；12M 均值 4.02/6.17/8.67；CAGR 4.00/6.00/8.01；回撤 -0.86/-2.33/-11.14。
- **口径校验**：2020-2026 CAGR 为 3.36/6.44/9.21；2008-2026 CAGR 为 4.00/6.00/8.01。
- **权重来源**：R1 用 2.2% 货币换信用债、0.7% 纳指换信用、0.3% 货币换短债；R2 减少偏债/黄金、增加一级债与科技；R3 降全球/纳指、增加科技/长债/一级债；CAGR 4.00/6.00/8.01，三组分别达 4/6/8；R3 的 -11.14% 是 2008 段结果，不是上限。
- **压力校验**：自然年、2018-2022/2023-2026 分段、日频滚动 12M、逐月起算 12M；结果见 6.1/6.2 和 1.2 图。
- **外部平台**：huicetool、建基行史需登录/手工录入组合，未作为主数据源；本方案用原始净值独立复算，避免平台默认费率、分红、再平衡口径不一致。

### 5.3 基金经理视角的六个概念

1. **风险预算，不是收益预测**：先定“最多亏多少”，再反推能买多少权益。R1 的 27.3% 货币+43.4% 短债不是“看空”，是 0.86% 回撤结果对应的风险配置。
2. **久期是利率债的杠杆**：006961 久期约 7 年；R3 的 8.4% 利率债，10Y +100bp 静态亏约 0.6%，2008-2026 实际回撤 11.14%。
3. **信用利差是 carry，不是免费收益**：400030/003859 的票息来自信用风险；2022 一级债、二级债也会跌。
4. **相关性在危机里会变**：红利与银行 0.75、黄金与股票平时 0.02，2022 年 +10.7%；科技/宽基已加回，R3 科技 7.3%。
5. **黄金是保险，不是生息资产**：R3 的 3.4% 黄金贡献约 2.1% 风险，但没有票息；它的作用是“股灾时能卖”。
6. **行为风险是最大风险**：R3 的 -11.14% 不是一天跌出来的；2008 年 -5.67%，2022 年 -3.75%。先决定能否扛 -11%，再选 R3。

### 7.3 税费/费用

- 管理费/托管费/销售服务费**已扣在净值**；不要再减。
- 申购费支付宝常 1 折；持有 <7 天赎回费 1.5%，7-30 天 1%，30-180 天 0.5%，>180 天多数 0；**20 年持有，不要短炒**。
- 分红税：基金内部已处理；个人层面按现行公募基金分红规则。
- QDII 溢价/汇率：实际买入价可能比净值高 1-5%，不要追高。

## 8. 风险与局限

1. **档位是历史回测，不是未来承诺**：真正年化（CAGR）4.00-8.01%，三组分别达到 4/6/8；前瞻情景未重算。如果 2026 后利率/黄金/美股回撤，R3 会先亏。
2. **R1 的 27.3% 货币已留出缓冲**：不是“看空”，是 0.86% 回撤结果对应的风险配置；4% 档 CAGR 为 4.00%。若继续压低货币，收益会升、回撤也会升；若提高货币，收益会跌破 4%。
3. **选择偏差**：基金池是“今天仍存续、业绩好”的样本，历史收益可能高 2-4pp/年；不要线性外推。
4. **2025 异常**：R3 2025 +11.89%，主要来自黄金/美股；如果 2025 不重复，R3 的 CAGR 8.01% 会明显回落。
5. **QDII 限购/溢价**：000834/096001 限购；大资金建仓慢，实际收益可能低于回测。
6. **主动基金风格漂移**：002969、003376、000307 新经理；001513 科技在 R3 为 7.3%，季度看持仓。
7. **代理误差**：1.2 图中的 2008†—2016† 含代理拼接；2017+ 逐步切换为实际净值，2008/2018 全年图与 6.1 的 5—12 月口径不可直接比较。
8. **没有完美组合**：R1 稳但收益 4%，R3 收益 8% 但 2008 年亏 -5.67%、最大回撤 -11.14%；先决定能接受 -0.86%、-2.33% 还是 -11.14%，再选。
